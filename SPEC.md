# Spec

- We want to make a static webapp we can host as a github page that connects to the Shining Mask (as made by the company Heaton which has the corresponding Shining Mask app on the google play store).
- The webapp should be able to automatically connect to the mask via bluetooth on my phone (where I will have the webapp open)
- The webapp should allow me to take a photo of my face with the phone camera
- It should isolate and line up the face with the mask screen
- It should slowly (or at a settable speed) morph that face more and more unrecognizably and animate that via the mask
